# **App Name**: GlobalPulse

## Core Features:

- Interactive World Map Display: Render a high-resolution, dark-mode interactive world map as the central dashboard element.
- Disease Outbreak Heatmap: Overlay a heatmap on the world map, visualizing active disease outbreak clusters using varying shades of orange and red for intensity.
- Date & Time Slider: Implement a user-friendly date slider control at the bottom of the dashboard to view historical outbreak data and cluster evolution.
- Subtle Map Controls: Integrate minimal and intuitive map controls (e.g., zoom, pan) that do not obstruct the data visualization.
- Outbreak Data Processor: A generative AI tool that processes raw global health data to identify, categorize, and prioritize active disease outbreak clusters for heatmap visualization.

## Style Guidelines:

- Color Scheme: Dark mode to provide a modern, focused canvas for data.
- Primary UI elements: A soft, deep indigo blue (#7381C0) to provide a calming, analytical tone and contrast against urgent data.
- Background: A very dark charcoal with a hint of blue (#141518), ensuring focus remains on the map and data overlays.
- Accent: A vibrant cool cyan (#54BBDA) for interactive elements, hover states, and key information, creating visual hierarchy.
- Heatmap Overlay: Gradient of orange to red (#FF6600 to #E60000) for disease outbreak intensity, as specified by the user.
- Body and headline font: 'Inter' (sans-serif) for its modern, clean, and highly legible appearance, suitable for data-driven dashboards.
- Use minimalist, vector-based icons for map controls and UI elements to maintain a clean aesthetic and prevent distraction.
- Centralized layout with the high-resolution world map as the primary focal point, flanked by subtle, non-intrusive controls and data displays.
- Smooth transitions and subtle animations for map interactions (zoom, pan) and heatmap intensity changes to provide a fluid user experience.
